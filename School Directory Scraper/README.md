# 🏫 School Directory Scraper (Dummy)

This is a sample project to scrape school names and emails from a paginated website.

### 🔧 Tools Used:
- Python
- Requests
- BeautifulSoup
- CSV

### 🧾 Output:
Data is stored in `data/sample_site_schools.csv` with columns:
- Name
- Email

### 📌 Notes:
- This script can be reused for any school directory website.
- Just inspect the correct HTML tags and replace them.

⚙️ Features

✅ Extracts data using tags or class selectors
✅ Handles pagination (optional)
✅ Saves output in clean CSV format
✅ Fully commented for beginners to learn
✅ Proxy support ready 
✅ Easy to customize for any site
